Preguntas Frecuentes

¿Es realmente seguro procesar mis archivos aquí?

Absolutamente. Al usar Python localmente, el código se ejecuta en tu máquina. Tus datos no se suben a la nube para ser procesados, lo que elimina el riesgo de intercepción.

¿Por qué mi navegador usa mucha memoria al procesar?

Debido a que el procesamiento es local, tu navegador actúa como el motor de transformación. Esto requiere recursos de RAM temporales mientras se realiza la tarea.

¿Puedo usar la herramienta sin conexión?

Una vez cargada la herramienta de procesamiento, muchas funciones seguirán operando incluso si pierdes la conexión, ya que el motor ya reside en tu sistema.

¿Cómo puedo reportar un error?

Puedes usar el botón de WhatsApp o enviarme un correo directamente. Agradezco mucho el feedback de la comunidad para seguir mejorando.
